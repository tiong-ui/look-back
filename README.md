# Look Back（回望）

An interactive web app for exploring world history on a map, centred on **Taiwan** and starting with **Asia**.

- 🗺️ A world map centred on Taiwan, with zoom and switchable map styles (streets, terrain, satellite, and others)
- 🕰️ A timeline slider for picking a date range from **1 BC to AD 2026**
- 📜 A sidebar table of major historical events in the selected range
- 📍 Links between events and the places they happened, plus links between related events
